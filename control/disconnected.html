Access control

Disconnect Control

Revoking the Intuit connection stops new QuickBooks API access. Any local credentials must also be removed from the owner’s Mac.

From QuickBooks Online

  1. Sign in to the correct QuickBooks Online company as an administrator.
  2. Open Apps, then My Apps.
  3. Find Control and choose Disconnect.
  4. Confirm that the app no longer appears as connected.

Remove the local token

Ask the owner or administrator to run the local Control disconnection procedure. It revokes the refresh token where possible, removes it from the restricted local configuration and verifies that the MCP server can no longer connect.

Delete retained copies

Delete the downloaded encrypted token package after import, and separately delete any Codex task, exported report or working paper that is no longer required. Revoking QuickBooks access stops future API calls but does not delete those existing copies.
